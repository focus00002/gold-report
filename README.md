# รายงานออมทองรายวัน (TrueMoney ออมทอง)

ระบบนี้รันอัตโนมัติทุกวันเวลา 09:30 บนคลาวด์ของ GitHub โดยไม่ต้องเปิดคอมไว้
ผลลัพธ์จะแสดงบนหน้าเว็บ (GitHub Pages) และ Google Sheet ดึงไปใช้ได้

## สิ่งที่ระบบทำทุกวัน

1. ดึงราคาทองแท่ง 96.5% ของวันนี้จากสมาคมค้าทองคำ
2. ดึงราคา Gold Spot กับค่าเงินย้อนหลัง 6 ปี เพื่อใช้ทำกราฟและคำนวณตัวชี้วัด
3. คำนวณเส้นเฉลี่ย 50 วัน, เส้นเฉลี่ย 200 วัน, RSI และ % ที่ลดลงจากจุดสูงสุด
4. ให้คะแนน 1-5 แล้วบอกว่าวันนี้ควรทำอะไร
5. จำลองผลลัพธ์ถ้าออมตามแผนมาตลอด 1, 3 และ 5 ปี
6. บันทึกรายงานลง `docs/report.csv` แล้วอัปเดตหน้าเว็บ

## แผนการออม: โควต้ารายวัน ทบยอด

- ได้โควต้าวันละ 100 บาท (ประมาณเดือนละ 3,000 บาท) เริ่มนับตั้งแต่ 22 พ.ย. 2569
- วันไหนสัญญาณได้ระดับ 4 หรือ 5 ให้ซื้อด้วยยอดที่ทบไว้ทั้งหมด
- วันไหนสัญญาณยังไม่ดี ให้ทบยอดไปวันถัดไป
- ถ้ารอครบ 14 วันแล้วสัญญาณยังไม่ดี ให้ซื้อเลย เพื่อไม่ให้เงินค้างนานเกินไป
- ถ้าสัญญาณระดับ 1 (แพงมาก) ระบบจะแนะนำให้ขายทองที่ถืออยู่ออก 15%
- ตั้งค่าได้ในส่วน `CONFIG` ด้านบนของไฟล์ `scripts/update.py`

### ยอดที่แนะนำให้ลง

- **ยอดสะสม** = โควต้าทั้งหมดตั้งแต่เริ่มแผน − เงินที่ซื้อจริงไปแล้ว
- **แนะนำให้ลง**:
  - สัญญาณระดับ 5: ยอดสะสม × 1.5
  - สัญญาณระดับ 4: ยอดสะสม
  - รอครบ 14 วัน: ยอดสะสม
  - อื่น ๆ: 0 บาท (ทบยอดไว้ก่อน)
- งบต่อครั้งสูงสุด 3,000 บาท ถ้าสูตรคำนวณได้เกิน หน้าเว็บจะแสดง "3,000 บาท+" พร้อมยอดที่สูตรคำนวณได้จริง
- ซื้อมากกว่ายอดสะสมได้ ส่วนที่เกินจะหักจากโควต้าวันถัดไป

ผลทดสอบย้อนหลัง (คำนวณ ณ 22 พ.ย. 2569) พบว่าวิธีทบยอดได้ผลใกล้เคียงกับการซื้อ 100 บาททุกวัน
และไม่ได้ดีกว่าอย่างชัดเจน เพราะช่วงที่ทองเป็นขาขึ้น การรอทำให้ต้องซื้อแพงขึ้น
หน้าเว็บมีตารางเปรียบเทียบสองวิธีนี้ และจะอัปเดตทุกวัน

## ความหมายของสัญญาณ

ระบบนับ "จุดซื้อ" และ "จุดขาย" แล้วเอามาหักลบกัน

| จุดซื้อ (+1 ต่อข้อ) | จุดขาย (+1 ต่อข้อ) |
|---|---|
| RSI ต่ำกว่า 35 | RSI สูงกว่า 70 |
| ราคาต่ำกว่าเส้นเฉลี่ย 50 วัน | ราคาสูงกว่าเส้นเฉลี่ย 50 วันเกิน 5% |
| ราคาต่ำกว่าเส้นเฉลี่ย 200 วัน | ราคาสูงกว่าเส้นเฉลี่ย 200 วันเกิน 15% |
| ลดลงจากจุดสูงสุด 52 สัปดาห์ตั้งแต่ 8% | ห่างจุดสูงสุด 52 สัปดาห์ไม่ถึง 2% |

| ระดับ | สัญญาณ | สิ่งที่ควรทำ |
|---|---|---|
| 5 | น่าซื้อมาก | ซื้อด้วยยอดที่ทบไว้ทั้งหมด |
| 4 | น่าซื้อ | ซื้อด้วยยอดที่ทบไว้ทั้งหมด |
| 3 | ปกติ | ทบยอดไว้ก่อน |
| 2 | ราคาแพง | ทบยอดไว้ก่อน |
| 1 | พิจารณาขายบางส่วน | ทบยอด และพิจารณาขายทองออก 15% |

สัญญาณนี้เป็นสูตรทางเทคนิค ไม่ใช่คำแนะนำการลงทุนจากผู้เชี่ยวชาญ
ราคาในแอปทรูมันนี่อาจต่างจากราคาสมาคมฯ เล็กน้อย

## วิธีติดตั้ง (ทำครั้งเดียว)

1. เข้า https://github.com/new แล้วสร้าง repository ใหม่ ตั้งชื่อเช่น `gold-report`
   เลือก **Public** (GitHub Pages ฟรีต้องเป็น Public) แล้วกด Create repository
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้นไป (ให้ Claude ทำให้ได้ด้วยคำสั่ง git)
3. ไปที่ **Settings > Pages** แล้วตั้ง Source เป็น "Deploy from a branch"
   เลือก Branch `main` โฟลเดอร์ `/docs` แล้วกด Save
4. ไปที่แท็บ **Actions** ถ้ามีปุ่มให้เปิดใช้ workflow ให้กดเปิด
   จากนั้นเลือก "Daily gold report" แล้วกด **Run workflow** เพื่อทดสอบรอบแรก
5. รอประมาณ 1-2 นาที แล้วเปิดหน้าเว็บที่
   `https://<ชื่อผู้ใช้ GitHub>.github.io/gold-report/`

## เชื่อมกับ Google Sheet

1. สร้าง Google Sheet ใหม่
2. พิมพ์สูตรนี้ในช่อง A1:

   ```
   =IMPORTDATA("https://<ชื่อผู้ใช้ GitHub>.github.io/gold-report/report.csv")
   ```

3. Google Sheet จะดึงรายงานรายวันมาเองอัตโนมัติ (รีเฟรชทุก 1 ชั่วโมงโดยประมาณ)

## บันทึกการซื้อจริง

วิธีง่ายสุด: หลังซื้อหรือขายในแอปทรูมันนี่ ให้กดปุ่ม **บันทึกการซื้อ** หรือ **บันทึกการขาย** บนหน้าเว็บ

1. ฟอร์มใน GitHub จะเปิดขึ้น พร้อมกรอกวันที่และยอดแนะนำไว้ให้แล้ว
2. แก้จำนวนเงินให้ตรงกับที่ซื้อจริง และจะใส่จำนวนกรัมที่ได้ด้วยก็ได้
3. กด **Create** ระบบจะบันทึก ตอบกลับในฟอร์มนั้น และอัปเดตหน้าเว็บภายใน 1-2 นาที

ต้องล็อกอิน GitHub ด้วยบัญชีเจ้าของ repo เท่านั้น ถ้าคนอื่นส่งฟอร์มมา ระบบจะไม่บันทึก

อีกวิธีคือแก้ไฟล์ `data/my_purchases.csv` เอง:

```
date,type,amount_thb,price_per_baht,note
2026-11-30,buy,1500,57150,ทรูมันนี่
```

- `type` ใส่ `buy` สำหรับซื้อ หรือ `sell` สำหรับขาย
- `price_per_baht` คือราคาต่อ 1 บาททองคำ ณ ตอนซื้อ

แค่ส่งข้อมูลให้ Claude แล้วให้ช่วยบันทึกก็ได้
